# bilalmeccai.com

Personal brand website for Mohammed Bilal Meccai — Senior DevOps Engineer.

## Stack
- Pure HTML / CSS / Vanilla JS
- Zero dependencies — no build step needed
- Deployed on Vercel via static hosting

## Local Development
```bash
# Just open in browser
open index.html

# Or use a local server
npx serve .
```

## Deploy to Vercel
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

## Structure
```
bilalmeccai/
├── index.html      # Full site (single file)
├── vercel.json     # Vercel config + headers
└── README.md
```
